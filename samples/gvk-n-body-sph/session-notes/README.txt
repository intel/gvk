SESSION NOTES DIRECTORY
================================================================================

This directory contains session notes for the SPH N-Body simulation project.

?? QUICK START:
  1. Read session-startup.txt (comprehensive guide)
  2. Review most recent YYYY-MM-DD-*.txt file
  3. Begin working

?? FILES:
  • session-startup.txt - Read this at the start of every session
  • ####-*.txt - Session logs (highest number = most recent)
  • README.txt - This file

?? NAMING CONVENTION:
  Format: ####-TOPIC.txt (sequential: 0000, 0001, 0002, etc.)
  Example: 0000-sleep-wake-implementation.txt
           0001-context-management.txt
           0002-performance-profiling.txt

  • Files sort numerically by name
  • Number increases with each session
  • Topic gives context at a glance

? CHECKPOINT WORKFLOW:
  Every 10-15 message exchanges:
    1. Say: "Create checkpoint session notes"
    2. Save your work, commit if appropriate
    3. Start a NEW chat session
    4. New session: "Review session-startup.txt and most recent notes"

?? IMPORTANT:
  • Use next sequential number (e.g., if 0005 exists, create 0006)
  • Always use #### format (four digits: 0000, 0001, 0010, 0099, etc.)
  • Keep bullet summaries at the top of each session note
  • Include detailed notes in the body

?? PURPOSE:
  Prevent context bloat and preserve decisions/learning across sessions.
  GitHub Copilot sessions fail at ~1.18 MB context (~20-30 exchanges).
  This system allows unlimited work while maintaining context.
