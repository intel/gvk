CONTEXT:
This was the initial push to add sleep/wake optimization to the SPH N-Body
simulation. The goal is to achieve 40x performance improvement by having 90-99%
of particles "asleep" (skipping physics) at steady state.

PARTICLE STRUCT CHANGES:
Added two new fields to support sleep/wake:
  uint32_t sleepCounter;  // 0 = awake, >= SLEEP_THRESHOLD = asleep
  float wakeRadius;       // Distance for wake-up detection (radius*scale*1.2)

Both fields added to:
  1. C++ struct in utilities.hpp
  2. GLSL struct in create-compute-pipeline.hpp (compute shader)
  3. GLSL struct in create-graphics-pipeline.hpp (vertex shader)

All three MUST match exactly for GPU buffer compatibility.

SLEEP/WAKE CONSTANTS:
Defined in compute shader:
  const uint SLEEP_THRESHOLD = 20u;           // Marker value (was 60 in earlier design)
  const float SLEEP_VELOCITY_THRESHOLD = 0.01;  // Instant sleep if below this
  const float WAKE_RADIUS_MULTIPLIER = 1.2;     // Wake detection margin

Design Decision: SLEEP_THRESHOLD changed from 60 to 20 frames to make particles
sleep faster. This is a tunable parameter for performance vs responsiveness.

SLEEP/WAKE LOGIC (Currently Disabled):
The compute shader has this code but it's commented out:

  // Early-exit for sleeping particles
  bool isAsleep = (p.sleepCounter >= SLEEP_THRESHOLD);
  if (isAsleep) {
      particles[index] = p;  // Write back unchanged
      return;                // Skip ALL physics
  }

And at the end of the shader:
  // Keep particles awake for debugging
  p.sleepCounter = 0u;

  // Update wake radius based on current scale
  p.wakeRadius = p.position.w * p.scale * WAKE_RADIUS_MULTIPLIER;

WHY DISABLED:
Sleep system is disabled to verify base physics work correctly first. Once we
confirm SPH forces, collisions, and rendering are stable, we'll re-enable and
test the performance gain.

INITIALIZATION:
All particle initialization functions updated to set:
  - sleepCounter = 0 (all particles start awake)
  - wakeRadius = radius * scale * 1.2 (calculated once)

Functions updated:

SHADER EXTRACTION:

This allows Copilot to reference just the shader code without loading all of
main.cpp (which previously caused context overflow).

DECISIONS MADE:
1. Sleep threshold set to 20 frames (down from 60) for faster sleep
2. Sleep system disabled until base physics verified
3. Shaders extracted to separate headers for context management
4. Wake radius calculated as radius * scale * 1.2 (20% margin)
5. Sleeping particles skip ALL physics (complete early-exit)

LESSONS LEARNED:
• Large shader code in main.cpp causes context bloat quickly
• Separating shaders into headers helps immensely
• Sleep counter as a marker (>=20 = asleep) is simpler than frame counting
• Need to test base physics thoroughly before adding optimizations
