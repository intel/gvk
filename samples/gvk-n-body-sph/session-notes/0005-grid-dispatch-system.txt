KNOWN ISSUES
================================================================================

Grid Occupancy Performance
  * CPU-side computation is expensive (534K cell loop + 10K particle loop)
  * Causes performance drops even with throttling
  * Particle interaction can feel sluggish when enabled

This is INTENTIONAL - temporary debug tool
  * Proper solution: Move to GPU in Milestone 2 (binning pass)
  * GPU will be 100x+ faster (parallel, no CPU overhead)
  * Current version useful for paused screenshots and debugging

Recommendation: 
  * Use "Show Grid Occupancy" only when paused or for analysis
  * Disable during interactive use or performance testing

================================================================================
LESSONS LEARNED
================================================================================

1. VkRenderPassCreateInfo vs CreateInfo2
   * Must check sType and handle both versions
   * Pattern: if (sType == CreateInfo) else CreateInfo2
   * Use std::max() across all attachments for sample count

2. Vertex Buffer Binding
   * WRONG: &(VkBuffer&)gvkBuffer (creates temporary reference)
   * RIGHT: VkBuffer vkBuf = gvkBuffer.get<VkBuffer>(); &vkBuf

3. Variable Lifetime
   * Temporary vectors destroyed after initialization
   * Store persistent data separately (gridLineVertexCount)
   * Cannot call .size() on destroyed std::vector

4. Build Directory Mistakes (REPEATED MULTIPLE TIMES)
   * NEVER edit files in build/ directory
   * Changes lost on rebuild
   * Always work in samples/ source directory
