??? ARCHITECTURE NOTES
================================================================================

Particle Struct (GPU-Matched Layout):
  struct Particle {
      glm::vec4 position;      // xyz=position, w=radius
      glm::vec4 velocity;      // xyz=velocity, w=mass
      glm::vec4 color;         // rgba color
      glm::vec4 force;         // xyz=force, w=padding
      glm::vec4 homePosition;  // xyz=original position, w=padding
      float density;           // SPH density
      float pressure;          // SPH pressure
      float scale;             // Visual scale (0.1x to 128x)
      float wakeRadius;        // Wake detection radius
      uint32_t gridCell;       // Spatial grid cell (unused currently)
      uint32_t sleepCounter;   // 0=awake, >=SLEEP_THRESHOLD=asleep
      float padding1, padding2;
  };

Sleep/Wake Constants:
  - SLEEP_THRESHOLD = 20 frames (marker value for asleep state)
  - SLEEP_VELOCITY_THRESHOLD = 0.01 (immediate sleep if below)
  - WAKE_RADIUS_MULTIPLIER = 1.2 (wake detection margin)

Sleep/Wake Logic (When Re-Enabled):
  - Sleep: velocity < 0.01 ? immediately mark as asleep (counter=20)
  - Wake: sleeping AND awake particle within wakeRadius ? set counter=0
  - User interaction (click/scale) ? immediate wake (counter=0)
  - Physics: Skip ALL physics for sleeping particles (early return)

Initialization Modes:
  1. UniformRandom (DEFAULT) - Even distribution
  2. GaussianCloud - Clustered in center
  3. MultipleClusters - Multiple groups
  4. Explosion - Radial velocity pattern
  5. StableGrid (TODO) - Pre-spaced grid, all asleep

Performance Optimizations:
  - Adaptive sampling: Skip physics checks when count > 50K
  - Distance culling: Squared distance checks, skip beyond interaction radius
  - 2D optimized: All Z calculations eliminated
  - Sleep system: Skip physics entirely for sleeping particles (when enabled)
  - Hard collision priority: Collision forces override SPH when overlapping

Rendering:
  - Compute shader: SPH physics (256 threads per workgroup)
  - Vertex shader: Instanced billboard quads (one quad per particle)
  - Fragment shader: Circle with soft/hard edges, selection highlighting

Critical Implementation Notes:
  - Particle buffer allocated at kMaxParticleCount (1M) for runtime resizing
  - All structs MUST match between C++, compute shader, and vertex shader
  - Collision strength = 5000 base, scaled with particle size
  - Selected particle uses color override (yellow/orange)
  - Mouse picking uses screen-space projection (not ray-cast)
